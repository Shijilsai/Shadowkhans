# SHADOWKHANS

**Creative & Digital Studio**

Premium dark-themed agency landing page built with cinematic aesthetics, glassmorphism, animated rings, and smooth parallax effects.

## Live Preview
> Deploy via GitHub Pages: Settings → Pages → Branch: main → / (root)

## Tech Stack
- Pure HTML/CSS/JavaScript
- No frameworks or dependencies
- Google Fonts (Bebas Neue, Syne, DM Sans)
- Custom cursor, scroll reveal, parallax mouse effects

## Features
- Animated background rings & glow blobs
- Glassmorphism floating orb
- Metallic shimmer hero title
- Infinite marquee ticker
- Portfolio grid with hover overlays
- Scroll-triggered reveal animations
- Responsive (mobile hamburger menu)
- Contact form

```
Shadowkhans/
└── index.html   # Complete single-file landing page
```
